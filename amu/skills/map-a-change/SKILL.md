# Map before you touch anything

## When to use
map-a-change

## Steps
- before changing graph-relevant source, run `amu map --symbol <path#name> --change <class>`
- read the radius and resolution; every guessed/unknown node has a verify line
- approve only when the focus is exact, evidence is complete, and the worktree stayed stable; a map made after source edits is inspection-only

## Done when
- the approved map is a stable pre-edit baseline, or uncertainty has been escalated instead of approved
